# HVACplan

Εφαρμογή για όψεις και διαστάσεις 3D κομματιών, μέσα στον browser.

**Άνοιγμα:** https://manolis08.github.io/HVACplan/

## Τι κάνει

- Έτοιμα σχήματα με διαστάσεις που αλλάζεις (mm)
- Άνοιγμα αρχείων 3D: GLB, glTF, STL, OBJ
- 7 όψεις (πρόσοψη, κάτοψη, πλάγιες, πίσω, κάτω, ισομετρική)
- Φύλλο όψεων A3 με κρυφές γραμμές, άξονες και υπόμνημα
- Εξαγωγή σε PDF, PNG και SVG
- Δουλεύει και χωρίς internet· τα αρχεία δεν φεύγουν από τη συσκευή

## Τοπικά

```bash
npm install
npm run dev
```
